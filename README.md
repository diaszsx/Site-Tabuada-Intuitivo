# 🧮 Site Tabuada Intuitivo

Um site interativo criado para tornar o aprendizado e a prática da tabuada mais simples, rápida e intuitiva.

## ✨ Recursos

* 📚 Tabuada de multiplicação
* 🧠 Prática para memorização
* ⚡ Interface rápida e intuitiva
* 📱 Design responsivo
* 🎨 Interface moderna e organizada
* 🔢 Interação dinâmica com JavaScript

## 🛠️ Tecnologias

* HTML5
* CSS3
* JavaScript

## 🎯 Objetivo

Facilitar o aprendizado da tabuada por meio de uma experiência simples, visual e interativa, permitindo que o usuário pratique de maneira rápida e eficiente.

## 📌 Projeto

Este projeto foi desenvolvido como uma aplicação web para estudo e prática de programação, além de servir como ferramenta de apoio ao aprendizado da matemática.
